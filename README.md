# Durable Agent Runner Requirements

A requirements checklist for evaluating or building any cloud agent runner before trusting it with real code or ops work.

Inspired by: https://x.com/cursor_ai/status/2061878340265656620

## What it contains
- `artifact-package/` — Obsidian package note
- `prototype/` — concrete markdown prototype
- `infographic/` — workflow explanation
- `skill-draft/` — reusable procedure draft
- `improvement-loop/` — recurring improvement tracker

## Latest improvement
- 2026-06-11: Added `prototype/Runner Post-Trial Debrief Template.md` so the next real runner trial can turn source-backed evidence into a promote / pilot-only / iterate / hold decision and a concrete README/prototype/skill patch queue. Template-ready only; validation still depends on a real trial.

## Quickstart
Read `prototype/README.md`, then use `prototype/Live Runner Trial Kickoff Card.md`, `prototype/Runner Trial Source Matrix.md`, `prototype/Live Runner Trial Packet.md`, and `prototype/Runner Post-Trial Debrief Template.md` against one real workflow.

## Roadmap
- Fill the live trial packet with a real runner task.
- Complete the post-trial debrief with exact source links.
- Promote or merge the skill draft only after reuse evidence is attached.
